# Datasets

Descarrega os ficheiros do Kaggle e coloca os CSVs nesta pasta.

| Dataset | URL | Target esperado |
|---|---|---|
| IoT Intrusion Detection | https://www.kaggle.com/datasets/rahult25/iot-intrusion-detection-dataset | `label` |
| Enron Fraud Email Dataset | https://www.kaggle.com/datasets/advaithsrao/enron-fraud-email-dataset | `Label` ou `label` |
| Malware Executable Detection | https://www.kaggle.com/datasets/piyushrumao/malware-executable-detection | `label` |
| Keylogger Detection | https://www.kaggle.com/datasets/subhajournal/keylogger-detection | `Class` |

Os nomes dos ficheiros podem ser diferentes. O programa não depende do nome do CSV; usa as colunas para reconhecer o perfil.

Não incluí os datasets no ZIP porque são grandes e pertencem aos respetivos autores/fontes.
